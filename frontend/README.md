# TraceFlow frontend

Angular 21 + PrimeNG 21 single-page application. See the [main README](../README.md) for setup.

```bash
npm ci
npm start                      # http://localhost:4200, proxies /api to http://localhost:8080
npx ng test --watch=false      # unit tests (Vitest)
npx ng build                   # production build in dist/frontend/browser
```
